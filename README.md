# au-IC-Card-Tools
Tools for analyzing legacy au by KDDI IC Cards (UIM)

---

- **`8981300020123456780F_V0.3_6FE9_XXXX`**: 6FE9 Sample files. Originally for UnDual-SIM.
- **`ATR.py`**: ATR (Answer to Reset) parser script. Automatically parses input ATR.
- **`uim_parser.py`**: UIM <-> Phone communication log parser script. Use PulseView with [`sigrok_iso7816`](#sigrok_iso7816-decoder) decoder, right-click "Bytes" row, "export all annotations for this row", then parse it with this script.
- **`6FE9_checksum.py`**: Checksum calculator for 6FE9 files. Takes a decrypted 6FE9 file as input and outputs the calculated checksum.
- **`6FE9_decrypt_from_bin.py`**: Script to decrypt and parse encrypted 6FE9 binary files. Automatically extracts the decryption key or derives it from a manually provided ICCID; outputs both the decrypted 6FE9 binary file and the parsed plaintext parameters.
- **`6FE9_decrypt_from_parsed_log.py`**: Script to extract, decrypt, and parse 6FE9 file data from the text log generated by `uim_parser.py`. Automatically extracts the key; outputs the raw 6FE9 binary, decrypted 6FE9 binary, and parsed plaintext parameters.
- **`6FE9_encrypt.py`**: 6FE9 encryption script. Takes a decrypted 6FE9 binary and an ICCID as input, automatically derives the encryption key, recalculates and updates the checksum, and outputs the encrypted 6FE9 binary file.
- **`6FE9_encrypt_c.py`**: 6FE9 encryption script. Takes a decrypted 6FE9 binary and an ICCID as input, automatically derives the encryption key, recalculates and updates the checksum, and outputs both the encrypted 6FE9 binary file and a C language array source code.

- **`8981300020123456780F_V0.3_6FE9_XXXX`**：6FE9示例文件；用在UnDual-SIM里的
- **`ATR.py`**：ATR解析脚本；输入ATR自动解析
- **`uim_parser.py`**：UIM <-> 手机抓包数据解析脚本；使用PulseView软件加[`sigrok_iso7816`](#sigrok_iso7816解码器)解码器，右键Bytes行导出此行的解码数据，然后用此脚本解析
- **`6FE9_checksum.py`**：计算6FE9文件checksum的脚本；输入解密后的6FE9文件，输出checksum
- **`6FE9_decrypt_from_bin.py`**：解密并解析加密的6FE9二进制文件的脚本；自动获取密钥或手动输入ICCID，输出解密后的6FE9文件和解析的内容
- **`6FE9_decrypt_from_parsed_log.py`**：从uim_parser.py解析的txt中提取、解密并解析6FE9文件的脚本；自动获取密钥，输出原始6FE9文件、解密后的6FE9文件和解析的内容
- **`6FE9_encrypt.py`**：6FE9加密脚本；输入解密后的6FE9文件和ICCID，自动计算密钥，修正checksum，输出加密后的6FE9文件
- **`6FE9_encrypt_c.py`**：6FE9加密脚本；输入解密后的6FE9文件和ICCID，自动计算密钥，修正checksum，输出加密后的6FE9文件和C语言数组源码
